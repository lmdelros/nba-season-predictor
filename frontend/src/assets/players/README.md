# Player pictures for the award cards

Add a picture here named by the player's NBA.com ID, for example `1628983.png` for Shai Gilgeous-Alexander, and the award card for that player shows it in place of the team logo. Only `.png` files are picked up, at build time, so rebuild the frontend after adding one.

Use only pictures you made yourself or have the rights to; this folder ships in the public site.
